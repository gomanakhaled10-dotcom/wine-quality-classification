# Wine Quality Classification

## Project Overview
This project explores wine quality data using Python, with a focus on data preprocessing, exploratory data analysis, and machine learning classification.

## Objectives
- Explore and understand the dataset.
- Clean and prepare data for analysis.
- Perform exploratory data analysis (EDA).
- Apply Gaussian Naive Bayes classification.
- Evaluate model performance.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Model training and evaluation

## Project Files
- `wine_quality_classification.ipynb` — Jupyter Notebook containing the project workflow.
